Gerencie administradores, gere códigos de sala e cadastre os pares de palavras usados no jogo.

Como funciona

  1. O admin gera um código de sala e cadastra pares de artigos por dificuldade.
  2. O host usa o código para criar a sala, escolhe dificuldade, tempo por rodada e quantidade de rodadas.
  3. Os participantes entram com o mesmo código e um apelido.
  4. A cada rodada, todos partem do mesmo artigo e precisam chegar ao artigo-alvo clicando apenas em links internos da Wikipedia.
  5. Quando alguém chega, o tempo restante dos demais cai para 30 segundos.
